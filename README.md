# 🌍 Weekend Explorer  

Plan your perfect weekend getaway! ✨  
Discover **nearby hotels, attractions, and experiences** powered by **TripAdvisor API**.  


## 🚀 Features  
- 🔎 Search hotels & attractions in any city  
- 🏨 View photos, ratings, and key details  
- 📍 Find local experiences for spontaneous trips  
- 📱 Clean & responsive UI  

---

## 🛠 Tech Stack  

| Layer       | Technologies |
|-------------|--------------|
| Backend     | ☕ Java |
| Frontend    | 🌐 HTML, 🎨 CSS, ⚡ JavaScript |
| API         | 🌍 RapidAPI (TripAdvisor) |

## 📂 Installation  

1. Clone this repo  

   git clone https://github.com/Harshavardhan-2761/Weekend-Explorer.git
   cd Weekend-Explorer
2. Get your **TripAdvisor API key** from [RapidAPI](https://rapidapi.com).
3. Add your **Api Key** in the Application.properties ⚙️
4. Run the main class to run locally
